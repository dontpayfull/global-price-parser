# Ports to other languages

The TypeScript code in `src/` is the reference. Every port reads the same data and must
return the same output for the same input.

## Shared files

- `data/*.json`: generated by `scripts/gen-data.mjs` from Unicode CLDR. Never edit by hand.
  - `currencies.json`: `codes` (ISO 4217), `digits` (currencies that do not use 2 decimals),
    `regions` (region -> legal tender currencies, main first).
  - `tokens.json`: symbol or word -> possible currencies, default first.
  - `digits.json`: code point of the zero of every Unicode decimal digit block.
  - `units.json`: `global` (unit form -> unit), `language` (forms that depend on the language).
  - `locales.json`: what the TypeScript code asks `Intl` at runtime: `languages` (known
    language codes, `Intl.DisplayNames`), `likelyRegion` (`sv` -> `SE`, `Intl.Locale#maximize`),
    `regionLanguage` (`CH` -> `de`, `und-CH` maximized).
- `spec/cases/*.jsonl`: one case per line, `{fn, input, options?, expected}`, generated by
  `scripts/gen-cases.mjs` with the reference build. `fn` is `parsePrice`, `parsePrices` or
  `readPageSignals`; `expected` is the exact JSON the reference returns.

A port passes when every case in `spec/cases/` gives `expected`, field by field.

## Rules

- Same algorithm, file by file, same names where the language allows. No new heuristics, no
  dropped ones. When the reference looks wrong, do not fix it in the port: report it.
- No runtime dependencies. Strings only: plain text and HTML strings (the DOM node input and
  `getComputedStyle` are TypeScript only).
- `index` is an offset into the extracted text. The reference counts UTF-16 code units; a port
  counts in its own native unit and its test converts to UTF-16 before comparing.
- `amount` stays a string; `value` is the language's float.
- Output field names follow the language's convention, plus a function that returns the
  reference JSON shape (camelCase keys) for the tests.

## Updating

Change the TypeScript first, then `npm run gen`, `npm run build`, `node scripts/gen-cases.mjs`,
then make every port pass again.
